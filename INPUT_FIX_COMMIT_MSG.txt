Fix: Remove duplicate TouchButtons from main menu causing double-triggers

Root Cause:
Main menu had BOTH text-based clickable items AND TouchButtons processing
the same input events, causing duplicate action triggers on click/tap.

Changes:
- Removed redundant TouchButton code from main_menu_ui.go
- Text-based menu already handles touch via GetTouchOrMousePosition()
- Added structured logging to track input method (keyboard/mouse/touch)
- Added BUG FIX comments documenting the issue and resolution

Impact:
- Single unified input path prevents duplicate event processing
- Consistent input handling across keyboard, mouse, and touch
- Cleaner code with reduced complexity and memory footprint

Testing:
- Build verified: go build ./cmd/client succeeds
- Other menus verified: single_player, multiplayer, genre use consistent pattern
- Character creation verified: TouchButtons used legitimately for navigation
