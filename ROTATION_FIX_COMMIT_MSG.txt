Fix: Prevent division by zero crash in rotation component

BUG FIX: Phase 3.6 - Critical arithmetic safety issue in rotation system

**Issue:**
The RotationComponent.Update() method calculates angular velocity by dividing
by deltaTime without checking if deltaTime is zero. This could cause a crash
in edge cases such as:
- First frame initialization timing issues
- Paused state transitions
- Extreme lag spikes
- Time manipulation during debugging

**Location:** pkg/engine/rotation_component.go:104

**Root Cause:**
```go
// UNSAFE: No validation before division
r.AngularVelocity = rotationDirection * actualRotation / deltaTime
```

**Fix Applied:**
Added deltaTime validation before division to prevent crash:
```go
if deltaTime <= 0 {
    // Cannot calculate velocity with zero deltaTime
    return false
}
r.AngularVelocity = rotationDirection * actualRotation / deltaTime
```

**Impact:**
- Severity: Critical (would cause crash/panic)
- Likelihood: Low (only in edge cases)
- User Experience: Game crash during player rotation/aiming
