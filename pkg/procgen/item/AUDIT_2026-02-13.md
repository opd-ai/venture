# Audit: github.com/opd-ai/venture/pkg/procgen/item
**Date**: 2026-02-13
**Status**: Needs Work

## Summary
The item package provides procedural generation for weapons, armor, consumables, and accessories with seed-based deterministic generation. Test coverage is excellent at 91.8% and deterministic generation patterns are correctly implemented. However, critical integration gaps exist where newly-added Item fields (ClassRestrictions, SpellEffectID, SpellDuration, SpellTargetType, SpellRadius) are defined but never populated during generation, breaking integration with engine systems. Additionally, genre support is incomplete with horror and cyberpunk templates missing, and sci-fi consumables not implemented.

## Integration Status
The package integrates with multiple engine systems:
- ✅ **CraftingSystem** (`pkg/engine/crafting_system.go:46-57`) — Uses ItemGenerator
- ❌ **InventorySystem** (`pkg/engine/inventory_system.go:178-179`) — Expects ClassRestrictions to be populated by generator, but field is always empty
- ❌ **InventorySystem** (`pkg/engine/inventory_system.go:345,703-793`) — Expects SpellEffectID and related fields for scroll spell activation, but fields are always empty
- ✅ **ItemSpawning** (`pkg/engine/item_spawning.go:120`) — Uses ItemGenerator
- ✅ **LegendaryQuestSystem** (`pkg/engine/legendary_quest_system.go:18-29`) — Uses ItemGenerator
- ✅ **MiniGameSystem** (`pkg/engine/minigame_system.go:21-42`) — Uses ItemGenerator

**Critical Integration Gaps:**
1. **All generated items are usable by all classes** — ClassRestrictions field is never populated, so class-specific equipment restrictions are non-functional
2. **All generated scrolls are non-functional** — SpellEffectID and related fields are never populated, so consumable scrolls have no spell effects when used
3. **Genre system incomplete** — Only fantasy and sci-fi partial support; horror and cyberpunk mentioned in project overview but not implemented
4. **Sci-fi consumables missing** — Sci-fi genre has weapons and armor but no consumables (health packs, energy cells, etc.)

## Recommendations
1. **HIGH PRIORITY: Implement spell effect generation for consumable scrolls**
   - Add `SpellEffectIDs []string`, `SpellDurations []float64`, `SpellTargetTypes []string`, `SpellRadii []float64` fields to `ItemTemplate` struct
   - Populate spell effect fields in `GetFantasyConsumableTemplates()` for scroll templates (e.g., "Scroll of Fireball" → SpellEffectID: "fireball")
   - Update `generateSingleItem()` to copy spell effect data from template to item when `ConsumableType == ConsumableScroll`
   - Use RNG to select from template's SpellEffectIDs array for variety
   - Add test coverage: `TestScrollSpellEffectGeneration`, verify spell fields populated for scrolls but not potions

2. **HIGH PRIORITY: Implement class restriction generation for equipment**
   - Add `ClassRestrictions []string` field to `ItemTemplate` struct
   - Define class restrictions in weapon/armor templates:
     - Heavy weapons (axe, crossbow): ["warrior", "ranger"]
     - Staffs/wands: ["mage", "cleric", "necromancer"]
     - Light weapons (dagger, bow): ["rogue", "ranger"]
     - Heavy armor (plate): ["warrior", "cleric"]
     - Light armor (leather): ["rogue", "ranger", "mage"]
   - Update `generateSingleItem()` to copy ClassRestrictions from template to item (lines 155-178)
   - Add test coverage: `TestClassRestrictionsGeneration`, verify restrictions match templates

3. **HIGH PRIORITY: Implement horror genre templates**
   - Add `GetHorrorWeaponTemplates()` → ritual daggers, bone clubs, cursed blades, meat hooks
   - Add `GetHorrorArmorTemplates()` → tattered robes, bone armor, flesh suits
   - Add `GetHorrorConsumableTemplates()` → blood vials, sanity potions, cursed scrolls
   - Register in `NewItemGeneratorWithLogger()` at line 41-53
   - Add test coverage: `TestHorrorGenreGeneration`

4. **HIGH PRIORITY: Implement cyberpunk genre templates**
   - Add `GetCyberpunkWeaponTemplates()` → monowire, smart pistols, cyberdeck weapons, EMP grenades
   - Add `GetCyberpunkArmorTemplates()` → cyberware, ballistic vests, neural shielding, optical camo
   - Add `GetCyberpunkConsumableTemplates()` → stim packs, ICE breakers, neural boosters, quickhacks
   - Register in `NewItemGeneratorWithLogger()` at line 41-53
   - Add test coverage: `TestCyberpunkGenreGeneration`

5. **HIGH PRIORITY: Implement sci-fi consumables**
   - Add `GetSciFiConsumableTemplates()` → med packs, energy cells, nanobots, shield boosters
   - Register at line 48: `gen.consumableTemplates["scifi"] = GetSciFiConsumableTemplates()`
   - Add test coverage: `TestSciFiConsumableGeneration`

6. **MEDIUM PRIORITY: Extend ItemTemplate structure**
   - Ensure all Item fields can be expressed in templates for deterministic generation
   - Consider template inheritance or composition for shared properties
   - Document template field mappings in `templates.go` doc comments

7. **MEDIUM PRIORITY: Validate template completeness**
   - Add validation in `NewItemGeneratorWithLogger()` to ensure all registered genres have weapon, armor, and consumable templates
   - Log warning if genre has partial template coverage

8. **LOW PRIORITY: Update README coverage claim**
   - Change line 184 from "**93.8%**" to "**91.8%**" to match actual test coverage
